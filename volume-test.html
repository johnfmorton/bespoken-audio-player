iOS Volume Behavior Test

Open this page on the device you want to test (e.g. http://<your-mac-ip>:8888/volume-test.html while npm run dev is running).

0. Environment

1. Does audio.volume read back after setting?

Sets audio.volume = 0.5 on a detached element and reads it back. Note: modern iOS may accept and report the value even though it has no effect on actual output, so treat test 2 (the audible test) as the ground truth.

2. Does volume audibly change?

Plays 3 seconds at full volume, then 3 seconds at volume = 0.1. If both sound equally loud, programmatic volume has no effect on this device.

3. Does muted work?

Plays 3 seconds unmuted, then 3 seconds with muted = true. Silence in the second half means muting works.

4. The component itself

This player has the volume-control attribute. On devices where the read-back test fails, only the mute button should appear (no slider).
